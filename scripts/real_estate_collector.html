الاستخدام

  1. افتح صفحة نتايج بحث في أي موقع، ودوس الـ bookmark. هيضيف البيوت اللي في الصفحة.
  2. من اللحظة دي بيتابع: كل صفحة تفتحها أو فلتر تغيّره أو تحريك للخريطة، بيضيف البيوت اللي الموقع حمّلها. لو الصفحة بتعمل reload كامل (زي HAR)، دوس الـ bookmark تاني في الصفحة الجديدة؛ البيوت بتتجمع على بعض لنفس الموقع.
  3. Collect pages: بيجيب الصفحات اللي بعد كده لوحده، بين كل صفحة والتانية 10 ثواني، لو robots.txt بتاع الموقع سامح ولو الصفحة فيها البيانات.
  4. Collect details: بيفتح صفحة كل بيت في الخلفية، بين كل بيت والتاني 12 ثانية، ويكمّل الوصف والصور وسنة البناء والـ HOA و رقم الـ MLS.
  5. Download CSV، وبعدين حوّله لـ Excel منسق: 
    python scripts\collector_csv_to_excel.py "%USERPROFILE%\Downloads\real_estate_trulia_com_400_listings.csv"

السجلات العامة في Harris County (Houston)

سكريبت Python بيجيب من مواقع المقاطعة نفسها ويطلّع CSV و Excel منسق في Downloads:

python scripts\public_records.py tax-sales --hcad "%USERPROFILE%\Downloads\hcad_2026"
python scripts\public_records.py foreclosures --from 2026-11 --to 2026-12
python scripts\public_records.py hcad --data "%USERPROFILE%\Downloads\hcad_2026" --zip 77009 77018 --absentee
  • tax-sales: العقارات اللي داخلة مزاد الضرايب الجاي (Tax Office): العنوان والحالة وأقل مزايدة والقيمة المحكوم بيها وتاريخ الحكم ورقم حساب HCAD، ونسبة المزايدة للقيمة كمعادلة Excel. مع --hcad بيضيف سنة البناء والمساحة والغرف والقيمة السوقية. الـ resales مالهاش أقل مزايدة على صفحة المكتب.
  • foreclosures: فهرس إخطارات الـ foreclosure عند County Clerk لكل شهر بيع: رقم المستند وتاريخ البيع والتسجيل ولينك الإخطار. العنوان جوه الإخطار نفسه (PDF متصوّر).
  • hcad: سجل التقييم لكل عقارات المقاطعة (حوالي 1.6 مليون حساب) من ملفات hcad.org. بتفلتر بالـ ZIP ونوع العقار (--class A1 بيت لعيلة واحدة)، والمالك اللي ساكن في مكان تاني (--absentee)، أو بره Texas، ومن غير homestead، وعدد سنين الملكية، وسنة البناء، والقيمة. Excel بيشيل لحد 50 ألف صف (--limit)، والـ CSV فيه الكل.

السكريبت بيعرّف نفسه باسمه، وبيمشي على robots.txt، وبيستنى 5 ثواني بين كل طلب والتاني، وبيقف عند أي صفحة خطأ. قوايم المزادات والإخطارات مفيهاش أسماء. قايمة HCAD فيها اسم المالك وعنوان المراسلة زي ما المقاطعة بتنشرهم، ومن الإعفاءات بيظهر الـ homestead بس (من غير السن أو الإعاقة أو المحاربين القدامى).

كل موقع ليه مجموعته لوحده. لو الموقع رجّع صفحة تحقق أو CAPTCHA أو خطأ، الجمع بيقف فورًا ومش بيحاول يعدّيها. وأسماء الوكلاء وتليفوناتهم وإيميلاتهم مش بتتجمع.
